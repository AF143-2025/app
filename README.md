# 📱 متجر سما الخضراء للهواتف الذكية والصيانة
### Sama Al-Khadraa Mobile & Tech Store (Production-Ready)

متجر إلكتروني احترافي متكامل ومتجاوب بنسبة 100% مع شاشات الهاتف والكمبيوتر (Mobile-First)، مصمم بأعلى معايير الجودة والأداء والسرعة، مع الحفاظ على الهوية الرسمية لكافة الخدمات المتوفرة في الفرع.

---

## ✨ المميزات الرئيسية للمنصة

1. **الصفحة الرئيسية (Modern & Fast Homepage):**
   - سلايدر إعلانات تفاعلي لأحدث هواتف iPhone و Samsung.
   - قسم استعراض أحدث الأجهزة الأكثر طلباً مع تبويبات سريعة للتصنيف.
   - قسم عروض وتخفيضات الأسبوع الحصرية مع احتساب التوفير المالي.
   - استعراض خدمات المتجر المتكاملة (بيع وشراء، صيانة، تقسيط، صيرفة، شرائح، وسوفتوير).
   - معلومات الفرع في بغداد - الكرادة، ساحة الواثق، وساعات العمل مع الاتجاهات على الخريطة.

2. **كتالوج الأجهزة والبحث الذكي:**
   - فلاتر سريعة حسب الماركة (Apple, Samsung, Xiaomi, Anker).
   - فلاتر حسب حالة الجهاز (🟢 جديد كارتونة / 🔵 مستعمل مفحوص A+).
   - فلاتر نطاقات الأسعار وترتيب حسب الأحدث والأكثر طلباً.
   - كروت أجهزة خفيفة وسريعة مع زرين للتفاصيل والواتساب المباشر.

3. **صفحة تفاصيل المنتج المستقلة (`/product/[id]`):**
   - معرض صور عالي الوضوح مع شريط مصغرات.
   - محدد السعات التخزينية (128GB إلى 1TB) ونقاط ألوان تفاعلية.
   - جدول المواصفات الفنية التفصيلي المعتمد.
   - أزرار اتصال مباشر ومحادثة واتساب مجهزة برسالة تلقائية باسم وسعر الجهاز.
   - مشاركة الرابط عبر Web Share API ونسخ الرابط.

4. **التقسيط المعتمد داخل المحل (`/installments`):**
   - عرض تعريفي راقي لخدمة التقسيط داخل الفرع بدون كفيل للمشمولين.
   - استعراض البطاقات المصرفية المدعومة (الرافدين، الرشيد نخيل، الكي كارد، TBI).
   - أزرار تواصل مباشرة دون أي إجراءات أو حاسبات إلكترونية معقدة.

5. **ورشة الصيانة الفورية المعتمدة (`/maintenance`):**
   - استعراض خدمات صيانة الشاشات الأصلية، البطاريات، المذربورد والـ IC، والسوفتوير.
   - استمارة تسجيل طلب صيانة مسبق ونظام تتبع حالة الجهاز برقم التذكرة.

6. **الصيرفة وصرف الرواتب (`/salaries`):**
   - واجهة مالية متقدمة (Fintech Showcase) لخدمات صرف رواتب الدولة نقداً وفورياً.

7. **لوحة تحكم المدير المتقدمة (`/admin`):**
   - حماية مشددة بالتوكنات والجلسات الإدارية.
   - إمكانية إضافة وتعديل الأقسام والمنتجات مع خياري **رفع صورة من الجهاز** أو **رابط مباشر (URL)**.
   - إدارة الطلبات، المستخدمين، تذاكر الصيانة، وسجلات التدقيق المالي.

8. **السرعة، الأداء، وتهيئة محركات البحث (SEO):**
   - خلو كامل من الخطوط الخارجية المعطلة والاعتماد على `next/font/google` محلياً.
   - ضغط الصور بنسبة 85% وتفعيل تنسيقات WebP و AVIF.
   - خريطة موقع ديناميكية (`/sitemap.xml`) وملف توجيه الروبوتات (`/robots.txt`).
   - بيانات منظمة Schema.org للمتجر المحلي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router & Server Components)
- **Language:** TypeScript
- **Styling:** Tailwind CSS & Lucide Icons
- **Database ORM:** [Prisma ORM](https://www.prisma.io/)
- **Database:** SQLite (خفيفة وسريعة وقابلة للنقل لأي قاعدة بيانات مثل PostgreSQL)
- **State Management:** React Context API (سلة المشتريات، المفضلة، والمصادقة)

## 🚀 تعليمات التثبيت والتشغيل المحلي

### 1. استنساخ المستودع
```bash
git clone https://github.com/AF143-2025/app.git
cd app
```

### 2. تثبيت الحزم البرمجية
```bash
npm install
```

### 3. إعداد البيئة وقاعدة البيانات
قم بإنشاء ملف `.env` اعتماداً على `.env.example`:
```bash
cp .env.example .env
```
ثم قم بتطبيق مخطط قاعدة البيانات وبذر البيانات التجريبية:
```bash
npx prisma db push
node prisma/seed.js
```

### 4. تشغيل المشروع للتطوير
```bash
npm run dev
```
افتح [http://localhost:3000](http://localhost:3000) في متصفحك.

### 5. بناء وتشغيل نسخة الإنتاج
```bash
npm run build
npm run start
```
